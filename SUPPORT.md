# Support

Before opening an issue:

1. Confirm ReLand Host is running.
2. Confirm Screen Recording and Accessibility are granted.
3. Confirm both devices can reach each other on the same trusted LAN or
   Tailscale network.
4. Confirm the Mac is unlocked.
5. Recreate an expired pairing QR.
6. Run the latest build.

Public issues must not contain credentials, pairing payloads, personal
screenshots, terminal content, hostnames, private addresses, or file paths.
Use GitHub's security reporting flow for security-sensitive problems.
